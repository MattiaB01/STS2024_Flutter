# sts
Sistema Tessera Sanitaria

## Getting Started

Applicazione in Flutter per l'invio al sistema tessera sanitaria delle detrazioni fiscali per le professioni sanitarie.

Le fatture inviate, i dati degli utenti e i dati dell'invio
vengono memorizzati nel dispositivo cellulare tramite database embedded Sqlite.

Le api necessarie per l'esecuzione non sono presenti in questo repository.

Qui elencate le funzioni principali:
- inserimento nuova fattura
- modifica/cancellazione fattura inviata
- inserimento/modifica/cancellazione utente
- recupero password dimenticata
- caricamento dati per funzionamento in modalità demo/test
